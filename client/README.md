# 🍽️ FoodServer – Full-Stack Food Ordering App

FoodServer is a full-stack food ordering and delivery web application built using **Next.js** on the client side and **Node.js (Express)** on the server side.  
This project demonstrates a modern MERN-style architecture with API integration, authentication, state management, and a dynamic UI.

---

## 🚀 Tech Stack

### 🔹 **Frontend (Client — Next.js)**

- Next.js 14 / App Router
- React
- Tailwind CSS
- Redux Toolkit / Context API
- Axios for API communication
- JWT authentication handling
- Responsive UI design

### 🔹 **Backend (Server — Node.js)**

- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication
- REST API architecture
- bcrypt password hashing
- CORS handling

---

## 🔥 Features

### Client (Next.js)

- User Signup & Login
- Product listing (meals/foods)
- Product details page
- Add to Cart system
- Checkout flow
- Fully responsive UI

### Server (Node.js API)

- Authentication (Register/Login)
- CRUD APIs for products
- User data management
- Token generation with JWT
- Secure routes (middleware)
